I built this site to have one place for my projects and my writing.

## What I used

- **Angular 21** for the site itself
- **Markdown files** for blog posts, so publishing is just a Git push
- **GitHub Pages** for free hosting

## A code sample

Code blocks get their own styling:

```ts
const greeting = 'Hello, world';
console.log(greeting);
```

> Tip: every post is a Markdown file in `public/content/posts/`.
